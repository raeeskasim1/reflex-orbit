# Reflex Orbit

Wait for the signal. Tap when it turns green. Compare five reaction times without rushing the countdown.

## Try it

https://raeeskasim1.github.io/reflex-orbit/

Run five trials. Deliberately click too early once, then reset and try using the focused button with Space.

## How it works

A timer chooses a random waiting period. Once the signal appears, performance.now measures time until the tap. Clicking early cancels the timer. The latest five successful trials are averaged; page reloads clear them. It is a casual game, not a precise cognitive assessment.
